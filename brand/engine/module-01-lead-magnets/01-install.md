# Install: pick your path

Three ways in. They all run the same system. Pick by what you already have open, not by what sounds most impressive.

**If you're not sure, use Path A.** It takes about ten minutes, needs no terminal, and it's how most people should run this.

---

## Path A · Claude Project (recommended)

**Ten minutes. No terminal, no install, nothing to configure.**

1. Go to claude.ai and create a **new Project**. Call it whatever your content engine is called.
2. Open **Project knowledge** and paste in all four files from page 4 (The Skill Files), one at a time. Each goes in as its own document.
3. Paste in the brand context doc you filled out on page 2. This one matters most. Without it the output reads like anyone's.
4. In the chat, say: *"Build me a lead magnet from this transcript"* and paste a transcript.

That's it. The project remembers the system, so every future magnet is one message.

**Why this is the default.** The system is a set of instructions plus your context. A Project holds both permanently, so you never re-paste. Nothing else about the workflow needs to change.

---

## Path B · Claude Code (if you already use it)

**Fifteen minutes. More power, only worth it if you're already in a terminal.**

1. Make a folder. Anything, `content-engine` is fine.
2. Save the four files from page 4 into it as `.md` files, keeping the names.
3. Save your brand context from page 2 alongside them.
4. Create a `CLAUDE.md` in that folder containing:

```
Read _master.md plus the relevant subtype file before producing anything.
Read brand-context.md in full first. All output follows it.
```

5. Open Claude Code in that folder and say what you want built.

**What you get over Path A.** It writes real files to disk, so magnets accumulate as a library instead of living in chat history. And with the Notion MCP connected it builds the delivery page directly rather than you copying output across.

**What you don't get.** Anything the system does differently. Same instructions, same output.

---

## Path C · Any chat window

**Two minutes. Works in Claude, ChatGPT, anything. Slower per magnet.**

Paste the prompts from page 5 one at a time, in order. Feed each output into the next.

**The honest tradeoff.** Nothing remembers anything between steps, so you re-paste your brand context and the previous output every time. A magnet that takes one message in Path A takes eight or nine here. Use this to test whether the system is worth setting up properly, then move to Path A.

---

## Connecting Notion

The magnet ships as a Notion page. Three ways to get it there, fastest first.

**Paste it manually.** The system outputs the full page content. Make a Notion page, make the subpages, paste. Ten minutes per magnet and zero setup. **Start here.** Don't automate something you've done zero times.

**The Claude Chrome extension.** Connect Notion, and Claude builds the page structure directly. Saves the copying. Worth setting up around magnet three.

**The Notion MCP, Claude Code only.** Claude creates the pages, nests the subpages and sets the cover itself. Fastest once running, most setup to get there.

**One thing to know either way.** Every section of a magnet must be a real nested child page, not a heading on one long page. Automated or manual, check that before you ship. A seven-page magnet arriving as one scroll reads as a blog post, and that single detail changes how the whole thing is received.

## Before you build anything

Fill in page 2. It takes fifteen minutes and it's the difference between output that sounds like you and output that sounds like a tool.

Then read page 3, build one magnet, and score it on page 7 before you post it.

**Your first build will take a few hours.** Every one after that is about fifteen minutes. Don't judge the system on the first run.
