The only economics that matter here

One source in. Nine formats out. Nobody writes nine times.

Every format below is a separate skill file that already knows the shape, the funnel stage and the voice. The source is the same recording.
A voice note, a call recording, or a thing I actually built this week
Not an idea. Not a topic. A real piece of work with real detail in it, because the detail is the only thing that cannot be faked and the only thing worth reading.
If the source is thin, every one of the nine is thin. Garbage in, garbage out is the whole failure mode here.
