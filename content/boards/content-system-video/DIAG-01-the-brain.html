The shape of the whole thing

One brain file. Four folders. Everything else is downstream.

Nothing here is a plugin or a product. It is a git repo of markdown that Claude Code reads at the start of every session.
CLAUDE.md
Read first, every session. Who I am, who I serve, the beliefs, and a routing table that maps any incoming request to exactly one skill file. If the routing table is wrong, everything after it is wrong.
↓
skills/THE VERBS
How to do a thing. One file per format, not one per topic.
  • content/
  • lead-gen/
  • youtube/
  • research/
  • ops/
  • dm-setting/
  • creative-strategy/
A skill is a spec. It survives me.
brand/THE NOUNS
Who the output is for and how it has to sound.
  • positioning.md
  • audience.md
  • voice.md
  • beliefs
  • learnings.md
Swap this folder and the same skills write for someone else.
research/THE INPUTS
Raw material. Fetched once, saved forever, never re-fetched.
  • transcripts/
  • post-studies/
  • competitors/
  • weekly-briefs/
This is the part that compounds. Month twelve is not month one.
content/THE OUTPUT
What came out, kept so the next thing can be built from it.
  • posts/
  • boards/
  • sessions/
Output becomes input. That loop is the whole trick.
Structure of my own working repo as it stands 25 Aug 2026. Nobody sells this as a template. It is the layout that survived me correcting it over and over, and the folder names are real.
