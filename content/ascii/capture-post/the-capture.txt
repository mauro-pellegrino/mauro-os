│                                                                            │
│   you want the title, the cover and the first few lines in one             │
│   frame, because that's the unit that did the work                         │
│                                                                            │
│   when the cover is an infographic, copy the image itself,                 │
│   so the detail inside it survives the capture                             │
│                                                                            │

│   the link         everything else can be re-fetched from it               │

│                                                                            │
│   without a link, you've saved a screenshot of something                   │
