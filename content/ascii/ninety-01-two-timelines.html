┌─ THE TWO TIMELINES · pick one before you start, not at week three ─────────────────────────┐
│                                                                                            │
├─ THE ONE THAT ENDS AT WEEK THREE ──────────────────────────────────────────────────────────┤
│                                                                                            │
│   "I hope my first article hits and gets me clients"                                       │
│                                                                                            │
│   what happens        the first article does not hit                                       │
│                       there was no second number to fall back on                           │
│                       you read one data point as a verdict                                 │
│   so                  you stop                                                             │
│                                                                                            │
├─ THE ONE THAT SURVIVES ────────────────────────────────────────────────────────────────────┤
│                                                                                            │
│   "I'm going to publish 150 articles and it'll start landing                               │
│    somewhere in there"                                                                     │
│                                                                                            │
│   what happens        the first article still does not hit                                 │
│                       neither does the ninth                                               │
│                       nothing about that is new information                                │
│   so                  you keep going                                                       │
│                                                                                            │
├─ THE NUMBER NOBODY WANTS TO HEAR ──────────────────────────────────────────────────────────┤
│                                                                                            │
│   One account I run posted every single day for a full year before                         │
│   the first genuinely good call came through.                                              │
│                                                                                            │
│   Told up front, the owner would have done it anyway. Knowing it                           │
│   would have made that year survivable instead of demoralising.                            │
