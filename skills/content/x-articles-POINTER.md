# X Articles: the evidence-backed skill set lives in growthub-os

**Do not fork this. Point at it.**

The seven-skill set that turns any transcript or document into an X article is at:

```
~/growthub-os/skills/content/x-articles/
```

Read `README.md` there for the order. It is deliberately account-agnostic, so it works for @maurojpelle and @lorenzo_pravata without modification. Voice is layered on top, not baked in.

| File | Owns |
|---|---|
| `_corpus.md` | every number the set cites, from 41 real captures |
| `01-subject.md` | raw input to a shortlist of subjects |
| `02-first-screen.md` | cover + title + first three lines as one scored unit |
| `03-title.md` | three hard rules, six patterns |
| `04-cover.md` | eight archetypes with medians, four prompt families |
| `05-body.md` | skeleton, length target, rhythm, the one ask |
| `06-distribution.md` | companion post, reply keyword, measurement |
| `07-improve.md` | the loop that keeps all of the above honest |

## Why there is one copy and not two

`x-article-creator.md` already exists in both repos and they have drifted apart with nothing syncing them. Growthub's is 825 lines at v1.7, this repo's is 508 at v2.0. Neither knows the other exists.

Copying the new set here would repeat that in six months. One canonical home, one pointer.

## What this repo still owns

`brand/voice.md`, `brand/positioning.md` and `brand/audience.md`. The skills read voice from wherever they are run. This repo is where @maurojpelle's voice lives, and `skills/content/x-article-creator.md` is where its correction log lives.

## Two findings that override the older skill

Both measured, both in `_corpus.md`:

**Length.** The 1,800-3,000 word band medians 225,900 impressions. The 900-1,800 band medians 73,300. `x-article-creator.md` specs 800-1,200 words, which is the weakest band in the corpus.

**Title case.** Three accounts tested capitalised against lowercase titles and the capitalised one won every time, by 5x, 6x and 12x.
